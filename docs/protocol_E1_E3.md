# 추가 실험 E1·E2·E3 사전 등록 (2026-09-30, 실행 전 고정)

목적은 새 모델이 아니라 세 질문에 답하는 것이다.
① 단순 검사보다 나은가 (E1) ② 검사 결과가 늦게 나와도 작동하는가 (E2) ③ 검증 방식을 바꿔도 개선이 남는가 (E3).
결과가 좋지 않아도 조건과 결과를 남기면 완료다. 결과를 본 뒤 아래 조건을 바꾸지 않으며, 바꿀 때는 이 문서에 날짜와 이유를 적는다.

## 공통

- 점수는 이미 고정된 것만 쓴다. 대회 기간 = `outputs/predictions/pipeline_{spc_maxz,logreg,logreg_spc}.csv` (run_all.py 교차검증 OOF), 미래 기간 = 대회 labeled 전체로 학습한 같은 세 모델.
- 미래 기간: CN7 2020-10-27~11-03 (2,763부품, 불량 11), RG3 2020-11-04~11-06 (74부품, 불량 7). 원본 labeled_data.csv, 대회 눈금으로 표준화, Average_Screw_RPM 10/29 이후 ×10 보정 (보정 전 결과도 함께 보관).
- 외부 정보 표시: side(LH/RH)를 쓰는 방법과 미래 라벨을 쓰는 평가는 표에 `uses_external` 로 표시한다.
- 동점 처리: 라벨·원본 행 순서를 쓰지 않는다. 고정 seed 0~49 의 무작위 순서로 동점을 끊고 평균·표준편차를 보고한다.
- 사건 수를 함께 보고한다: 불량 부품 수와 불량 shot 수.

## E1 — 같은 검사량에서 방법 비교

- 예산 B = 전체 부품 수의 2 · 5 · 10 · 20 · 50 %, k = floor(B × N) 부품.
- 방법 (검사 순서)
  | 방법 | 순서 | 비용 단위 |
  |---|---|---|
  | random | 전체 부품 무작위 | 부품 |
  | rh_first | RH 부품 무작위 → LH 부품 무작위 | 부품 |
  | spc | 관리도 점수 높은 shot 부터, shot 의 모든 부품 | shot (부품 2개) |
  | logreg | 로지스틱 점수 높은 shot 부터, shot 의 모든 부품 | shot |
  | logreg_spc | 결합 점수 높은 shot 부터, shot 의 모든 부품 | shot |
  | logreg_spc_rh | 결합 점수 높은 shot 순, 각 shot 안에서 RH → LH (순서 정의 (a)) | 부품 |
- shot 단위 방법은 남은 예산이 다음 shot 비용보다 작으면 멈추고 남은 예산을 기록한다 (한 부품만 임의로 고르지 않는다).
- 지표: 포착률(TP/P), 적중률(TP/검사 부품), 미포착 수(FN), TP·FP·FN, 실제 검사 부품 수, 남은 예산, 불량 80% 포착에 필요한 검사율.
- 대회 기간 OOF 는 두 방식으로 순위를 매긴다: (i) 반복마다 전 fold 를 한 줄로 합쳐 순위 (본 결과), (ii) fold 마다 예산을 부품 수 비례로 나눠 fold 안에서 순위 (fold 간 점수 눈금 차이 점검).
- 평가 대상 열: 대회 기간 block CV (본), shot CV (참고), 미래 기간.
- RG3 해석 기준: RH 전수(약 50%)보다 적은 검사로 충분히 포착하는가. 못 보이면 "RG3 에서 모델의 추가 이득 미확보".

## E2 — 검사 결과 지연을 반영한 시간순 재생

- 재생 데이터: 미래 기간 (CN7 10/27~11/03, RG3 11/04~11/06). 모델은 대회 labeled 전체로 학습, 재생 기간 라벨은 규칙이 '도착한 검사 결과'로만 본다.
- 표기: 이 기간의 모델 점수 순위는 이미 확인했으므로 (2026-09-30 X3) "탐색적 날짜 검증"으로 쓴다. 독립 최종 테스트라고 쓰지 않는다.
- 임계값: 대회 기간 block CV OOF (반복 0) 점수의 상위 2 % · 5 % 분위수. 재생 기간 점수로 다시 정하지 않는다.
- 지연 d ∈ {0, 1, 3, 5} shot (민감도 조건, 현장값 아님). 용량: 10 shot 마다 최대 c ∈ {2, 4} 부품 검사, 넘는 요청은 미검사로 기록.
- 추적: 검사 결과가 도착해 불량이 확인되면 그 시점부터 다음 3 shot 을 검사 요청.
- 규칙: 모델만 / 모델+추적 / 모델+RH 우선(shot 요청 시 RH 부품 먼저, 용량 남으면 LH) / 모델+RH 우선+추적.
- 지표: 실제 검사율, 포착률, 첫 불량 생산 → 첫 불량 확인까지 shot 수, 용량 초과 요청 수, 사건(연속 불량 구간) 수.

## E3 — 모델 선택과 분할에 대한 점검

- 방법 셋만: logreg, spc_maxz, logreg_spc. 새 후보 추가 없음.
- 바깥 평가: 연속 block (크기 5 · 10 · 20 shot) 3-fold × 5 반복 (StratifiedGroupKFold, 기존 분할 규칙). 안쪽(바깥 학습 부분)에서 3-fold block CV 로 세 방법 중 하나를 선택 (shot AP 최고, 1-SE 로 단순한 쪽), 스케일러·백분위 기준·임계값도 안쪽에서만.
- 바깥 fold 별로 보고: 불량 부품 수, 학습 쪽 불량 수, 선택된 방법, 세 방법 각각의 바깥 AP·검사 10 % 포착률·오경보율.
- 평가 fold 에 불량이 없으면 AP 를 평균에 넣지 않고 "평가 불가"로, 학습 쪽에 불량이 없으면 "학습 불가"로 표시하되 행은 남긴다.
- block 분할은 앞뒤 구간이 학습에 들어가므로 "미관측 구간 검증"이라 쓰고 "미래 예측 검증"이라 쓰지 않는다.

## 변경 기록

- 2026-09-30 (E3 실행 전, E1 결과를 본 뒤): E3 안쪽 선택 지표를 "반복 OOF 를 합친 shot AP" 대신 **fold 안 shot AP 의 평균**(불량 있는 fold 만)으로 정함. 이유: E1 에서 fold 를 합쳐 순위를 매기면 fold 간 점수 눈금 차이 때문에 결합 모델이 유리하게 보이는 것을 확인 (합산 순위 검사 10% 포착률 로지스틱 0.49 / 결합 0.67 → fold 안 순위 0.61 / 0.60). 1-SE 는 안쪽 fold 간 표준오차로 계산.
- 2026-09-30 (E3 실행 전): E3 오경보율의 임계값 = 안쪽 OOF 점수 상위 10 % 분위수 (fold 안 순위와 같은 검사량 기준).
