## 2. 가설 우선순위
| 순위 | 가설 | 데이터 근거 (사실) | 문헌 근거 | 활용 방식 |
|---|---|---|---|---|
| 1 | RH 캐비티 금형 요인(벤트·충전 불균형) | RG3 가스·미성형 25/25 RH (이항검정 p≈6e-8), CN7 13/17 RH (p=0.049), 공정변수 차이 없음 | 가이드북(쇼트숏: 금형 내 공기저항), BASF(벤트), Beaumont·Bozzelli | 결론·권고 + 검사 규칙(RH 우선) + 캐비티별 분석 |
| 2 | 가동 초기 불안정 | CN7 불량 27행 전부 가동 후 60분 이내, 10/27 초기허용불량 = 재가동 직후 5샷 | 데이터 Reason 열 (외부 문헌 미확보) | 검사 규칙 ②(재가동 후 N샷) |
| 3 | 계량(재료 공급) 이상 → 미성형 | CN7 미성형 3샷 = 사출속도 급변 3샷, 쿠션 −0.01mm | 가이드북(원료 공급불량·충전압력 부족), BASF(계량 부족) | 해석 가설 (현장 기록 필요) |
| 4 | 열분해·체류시간 → 가스 | 실린더 온도·사이클 차이 없음 | 가이드북(실린더 고온→열분해), BASF, 헬로티 | 기각 근거로 보고 |
| 5 | 수분(건조 부족) → 가스·은조흔 | 호퍼 온도 차이 없음 (CN7 p=0.13, RG3 p=0.70) | BASF(수분 streak), 가이드북(호퍼=건조) | 기각 근거로 보고 (건조기 이슬점 데이터 없음) |

## 3. 가이드북 벤치마크 주의
- 가이드북 준지도 결과표의 평가 데이터 불량 수: RG3 83개, CN7 56개
- 실제 labeled 전체 불량: RG3 25행, CN7 27행 (공개 원본 기준)
- 평가 세트 불량이 전체보다 많다 → 불량 복제·증강 후 분할한 것으로 보임 (추정)
- 따라서 가이드북의 재현율 1.00 과 직접 비교하지 않고, '엄격한 검증에서 성능이 낮아지는 이유'의 근거로 쓴다.
