**RG3 E1c 검증: 순서 섞기 검정 (200회)**
- 방법: 샷 순서를 무작위로 섞어 가짜 '직전 샷' 피처를 만들고 같은 실험을 200회 반복
- 결과: 실제 0.0688, 섞은 경우 평균 0.0431 / 95% 분위 0.0569 / 최대 0.0718 → p ≈ 0.010 (200회 중 1회만 실제 이상)
- 해석: 신호는 피처 수가 늘어서가 아니라 **실제 생산 순서의 맥락**에서 나옴
- 한계: 변형 3개 중 가장 좋은 것을 본 결과라 다중비교 보정(×3) 시 p ≈ 0.03, 두 제품 6개 기준이면 ≈ 0.06

**CN7 에서 역효과가 난 이유 (해석)**
- CN7 불량은 샷 24~60 구간에 몰린 하나의 이상 사건
- '직전 샷 대비 변화'는 사건 안에서는 작아서, 불량 구간 전체가 오히려 정상처럼 보임
- 반대로 순서를 섞은 가짜 피처는 CN7 에서 0.216 까지 올라감 → 전역 이탈을 한 번 더 넣은 효과

## 결론과 다음 단계

# D 시리즈: 도메인 가설 실험 (2026-09-28)

## 조건
- 데이터: 공개 원본 `moldset_labeled.csv` (KAMP, 운영진 활용 허용 2026-09-28). 원 단위 값 + 시각
  - 대회 파일 = 이 값을 파일별로 표준화한 것 (23개 변수 모두 확인) → 기준 모델 CV 수치 동일 (CN7 0.188)
- 평가 (A): 레포 fold_id CV
- 평가 (B): **날짜 홀드아웃** (학습에 쓰지 않은 생산일에서 채점)
  - CN7: 10/16·19·20 학습 → 10/27 (대회 파일에 없는 날, 불량 5샷 = 초기허용불량)
  - RG3: 10/21·22 → 10/23, 10/21·23 → 10/22
- 사전 등록한 피처
  - 재가동 = 샷 간격 > 5분
  - D1 가동 초기: 재가동 후 경과 분·샷 수, 직전 정지 시간
  - D2 체류시간: 직전 샷 간격, 최근 10샷 평균 간격
  - D3: 관리도 고정 기준선 vs 이동 기준선 (직전 20샷, σ 하한 = 0.25 × 학습 정상 σ)

## 해석
1. **시간 피처(D1·D2)는 채택하지 않는다.**
   - 가동 초기 상태는 공정값 자체(재가동 직후 사출속도 상승 구간 등)에 이미 드러나 있다.
   - 시계 정보를 더하면 10/16 에만 있던 '가동 후 24~60분' 패턴을 외워 새 날짜 성능이 떨어진다.
2. **CN7 기준 모델은 처음 보는 날(10/27)에도 불량을 상위권에 올린다.** CN7 성능이 10/16 하루에 기대고 있다는 우려를 줄이는 독립 근거다.
   - 단, 10/27 불량은 '초기허용불량'(재가동 직후 5샷)으로, 학습한 가스·미성형과 사유가 다르다.
   - 모델이 잡은 것은 '공정값이 평소 범위를 벗어난 샷'이다.
   - 고정 기준선 관리도도 순위는 완벽하지만, 절대 기준(σ)으로는 정상 샷까지 경보한다 (이전 분석). 운영에는 순위(상위 k%) 기준이 필요하다.
3. **RG3는 날짜 홀드아웃에서 모든 방법이 무작위 수준이다.**
   - 공정변수로 설명되지 않는 불량이라는 결론을 강화한다. 불량 25건 모두 RH 캐비티이고 재가동 후 경과 시간과도 무관하다.
   - 금형(캐비티) 요인 가설을 뒷받침한다.
   - E1c 는 10/23 에서 0.058 (1.45배), 10/22 에서 0.053 (≈무작위) → 보고서 B안 문구는 '약한, 날짜에 따라 불안정한 신호'로 서술한다.
